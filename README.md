# Shalu — Dark Aesthetic Portfolio

A responsive personal portfolio made with plain HTML, CSS, and JavaScript. Designed for GitHub Pages.

## Publish on GitHub Pages

1. Create a **public** repository named `shalu2024.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait a few minutes, then visit https://shalu2024.github.io/.

## Personalize before sharing

Search `index.html` and update:
- `Shalu` and the About section to reflect your preferred name and real bio.
- `hello@example.com` with your public contact email.
- The LinkedIn link with your own profile URL.
- Skills, project titles, descriptions, technologies, and project links with your actual experience.

The project cards are placeholders; replace them with your real projects. Do not publish private contact details.
