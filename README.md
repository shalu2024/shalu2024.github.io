# Shalu — Frontend Portfolio

A simple one-page resume site for GitHub Pages.

Live site: https://shalu2024.github.io/

## Sections

Home, About, Resume (education + work), Skills, Works, and Contact.

## Publish

Push `index.html`, `style.css`, `script.js`, `shalu_resume2025.pdf`, and `README.md` to the `main` branch root, then enable GitHub Pages from `main` / `(root)`.
